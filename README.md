# Kuyruk Numarası Kaçıyor

Bu depo, Türkiye Cumhuriyeti Hayali Evraklar Genel Müdürlüğü adına, sıra numarasının neden hiç gelmediğini bilimsel olarak kanıtlar.

Sistem bozulmamıştır. Sistem tam olarak tasarlandığı gibi çalışmaktadır: senin numaran çağrılırken, çağrılan numara birkaç kişi önden kaçar. Banko çay içer. Mühür uyur. Adalet, PDF olarak ekteymiş gibi yapar.

## Kurulum

Python 3 yeter. Bağımlılık yoktur, çünkü bürokrasi de bağımlılık istemez, sadece bekletir.

```bash
python3 sira_kacir.py --numara 47 --tur 6
```

## Resmi Özellikler

- Sıran asla gelmez, ama terminal yeşil yanar.
- Bankolar: A, B, C, Çay, Mühür.
- Her turda yeni numara alırsın. Yeni numara daha kötüdür. Bu bir hata değil, sürüm notudur.
- Çıkış kodu her zaman 0'dır. Şikayet mercii kapalıdır.
